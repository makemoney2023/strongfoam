# Sales YouTube Frameworks (Standing Context)

Venture-agnostic sales training compiled from curated YouTube videos (objection handling, cold calling, closing, follow-up, psychology/rapport, etc.).

## Read order

1. This `SKILL.md`
2. Relevant file under `frameworks/` for the task (prefer topic MD over `all_frameworks.md` unless you need the index)
3. Optional: matching video under `analyses/` or catalog in `youtube_videos.json`
4. Apply ethically — discard high-pressure / manipulative tactics; keep discovery, clarity, and consent
