## Shared library

`claude-skills/` contains the extended skill library used across projects,
including web design, UI/UX Pro Max, React and Next.js best practices, shadcn,
accessibility, testing, security, product, marketing, data, and integrations.
Project and organization instruction files are intentionally not imported with
the library.
